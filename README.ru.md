# Veyron v1 для Windows

## Скачать

**[Скачать Veyron v1 — установщик для Windows](https://github.com/akaiboldiyev/Veyron/releases/latest/download/Veyron-v1-Installer.zip)**

Это единственная кнопка, которая нужна для скачивания. Архив появится в папке **Загрузки**.

Если открылась страница GitHub, прокрутите её до **Assets** и нажмите **Veyron-v1-Installer.zip**. Не нажимайте **Code → Download ZIP** и не скачивайте **Source code**: это исходники, а не приложение.

## Установить

1. Откройте папку **Загрузки** в Проводнике.
2. Нажмите правой кнопкой на `Veyron-v1-Installer.zip` → **Извлечь все…** → **Извлечь**.
3. Откройте созданную папку `Veyron-v1-Installer`.
4. Дважды щёлкните `Install-Veyron.vbs`. Не отделяйте папку `App` от этого файла.
5. Если Windows спросит, открыть ли файл, нажмите **Открыть**. Для этой установки не нужны терминал, сертификат или права администратора.
6. Дождитесь запуска Veyron. Позже приложение можно открыть через **Пуск → Veyron v1**; оно также запускается при входе в Windows и находится рядом с часами.

Установщик закрывает уже запущенную Veyron на время обновления и запускает её снова. Настройки и данные приложения при установке не удаляются.

## Если что-то пошло не так

- **«Файл используется другим процессом»**: скачайте установщик по кнопке выше, чтобы получить последнюю версию. Если ошибка повторится, нажмите правой кнопкой на значок Veyron рядом с часами → **Выход из Veyron**, затем запустите `Install-Veyron.vbs` ещё раз.
- **В архиве нет `Install-Veyron.vbs` или папки `App`**: скачан архив исходников. Вернитесь к кнопке **Скачать Veyron v1** выше и повторите шаги 2–4.
- **Windows показывает предупреждение при открытии сценария**: убедитесь, что файл находится в распакованной папке `Veyron-v1-Installer`, затем нажмите **Открыть**.

## Удалить

Откройте папку `Veyron-v1-Installer` и запустите `Uninstall-Veyron.vbs`. Приложение, ярлык и автозапуск будут удалены. Настройки и пользовательские данные в `%LOCALAPPDATA%\Cyclop` останутся на компьютере.

## О приложении

Veyron — компактная панель Windows на основе Cyclop. Она раскрывается у верхнего края экрана и управляет Яндекс Музыкой, полкой файлов, буфером обмена, заготовками текста и офлайн-переводом RU ↔ EN.

Требуется Windows 10 версии 1809 или новее либо Windows 11, x64. Установщик уже содержит компоненты приложения; отдельно устанавливать .NET не нужно.

### Сборка из исходников

Разработчикам нужны PowerShell и .NET 8 SDK:

```powershell
.\Windows\Build-Windows.ps1
```

Сборка установщика появится в `build/Windows/Veyron-v1-Installer.zip`. Исходники исходной версии для macOS находятся в `Sources/Cyclop`.
