# Veyron v1

Панель для Windows на основе проекта Cyclop. Veyron раскрывается от верхнего края экрана и остаётся в области уведомлений, чтобы открываться по наведению.

*[English](README.md) · Русский*

## Установка без терминала

### Скачать

Нажмите эту ссылку, чтобы скачать архив установщика: **[Скачать Veyron v1 для Windows (.zip)](https://github.com/akaiboldiyev/Veyron/releases/latest/download/Veyron-v1-Installer.zip)**.

Если хотите открыть страницу релиза вручную:

1. Перейдите на [страницу релизов Veyron](https://github.com/akaiboldiyev/Veyron/releases/latest).
2. В блоке **Assets** нажмите **Veyron-v1-Installer.zip**. Не скачивайте `Install-Veyron.vbs` отдельно и не нажимайте **Source code**.
3. Дождитесь окончания загрузки. Архив появится в папке **Загрузки** браузера.

### Установить

1. Откройте папку **Загрузки** в Проводнике Windows.
2. Нажмите правой кнопкой на `Veyron-v1-Installer.zip` и выберите **Извлечь все…**, затем нажмите **Извлечь**.
3. Откройте созданную папку `Veyron-v1-Installer`.
4. Дважды щёлкните **Install-Veyron.vbs**. Файлы `Veyron-v1.msix` и `Veyron-v1.cer` должны оставаться в этой же папке.
5. После сообщения об успешной установке откройте Veyron из меню **Пуск**. Он также появится в области уведомлений рядом с часами.

Если Windows покажет подтверждение запуска сценария, нажмите **Открыть** или **Запустить**. Если появилось сообщение «Не найден Veyron-v1.msix», значит архив не был извлечён целиком: вернитесь к шагу 2 и запустите скрипт из созданной папки.

Veyron запускается при входе в Windows. Чтобы отключить автозапуск, нажмите правой кнопкой по значку Veyron в области уведомлений и снимите флажок **«Запускать при входе в Windows»**. Пункт **«Выход из Veyron»** закрывает приложение до следующего запуска. Автозапуск также отключается в **Veyron → Настройки** или в **Параметры Windows → Приложения → Автозагрузка**.

Чтобы удалить приложение, запустите `Uninstall-Veyron.vbs` из распакованной папки или удалите **Veyron v1** через **Параметры Windows → Приложения → Установленные приложения**. Сохранённые данные останутся в `%LOCALAPPDATA%\Cyclop`.

> Пакет подписан сертификатом разработки, создаваемым при сборке. Установщик добавляет его в доверенные сертификаты только вашей учётной записи Windows. Для публичного распространения нужна подпись издателя, доверенная Windows.

## Возможности

- Управление Яндекс Музыкой, текущим треком и воспроизведением.
- Полка файлов с перетаскиванием, превью и отслеживанием папки скриншотов.
- История буфера обмена и шаблоны текста.
- Офлайн-перевод RU ↔ EN через Argos Translate.
- Дополнительные инструменты и настройки в компактной плавающей панели.

## Требования

- Windows 10 версии 1809 или новее, либо Windows 11.
- Windows x64.

Установщик содержит всё необходимое для запуска: пользователю не нужны .NET и терминал.

## Сборка из исходников

Для разработчиков нужны PowerShell и .NET 8 SDK:

```powershell
.\Windows\Build-Windows.ps1
```

Готовый установщик появится в `build/Windows/Veyron-v1-Installer.zip`. В репозитории сохранены исходники исходной macOS-версии в `Sources/Cyclop`.
