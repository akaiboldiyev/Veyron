VEYRON V1 — СКАЧИВАНИЕ И УСТАНОВКА БЕЗ ТЕРМИНАЛА

1. Откройте страницу https://github.com/akaiboldiyev/Veyron/releases/latest.
2. В разделе Assets нажмите Veyron-v1-Installer.zip. Не скачивайте Install-Veyron.vbs отдельно и не выбирайте Source code.
3. В Проводнике откройте папку Загрузки.
4. Нажмите правой кнопкой на Veyron-v1-Installer.zip → Извлечь все… → Извлечь.
5. Откройте созданную папку Veyron-v1-Installer.
6. Дважды щёлкните Install-Veyron.vbs. Рядом должны лежать Veyron-v1.msix и Veyron-v1.cer.
7. Во время установки откроется окно PowerShell. Ничего вводить не нужно — дождитесь сообщения.
8. Установщик объяснит, что Windows покажет запрос доверия издателю Veyron для вашей учётной записи. В системном окне нажмите «Да», только если скачали комплект с официального релиза https://github.com/akaiboldiyev/Veyron/releases/latest.
9. После подтверждения установки откройте Veyron v1 из меню Пуск. Значок приложения также будет рядом с часами.

Veyron запускается при входе в Windows. Чтобы отключить автозапуск, нажмите правой кнопкой по значку Veyron в области уведомлений и снимите флажок «Запускать при входе в Windows». Пункт «Выход из Veyron» закрывает приложение до следующего запуска.

Чтобы удалить приложение, откройте «Uninstall-Veyron.vbs» или удалите Veyron v1 через Параметры Windows → Приложения → Установленные приложения. Настройки и пользовательские данные останутся в %LOCALAPPDATA%\Cyclop.

Этот комплект подписан сертификатом разработки для установки текущим пользователем. Для публичного распространения нужна подпись издателя, доверенная Windows.
