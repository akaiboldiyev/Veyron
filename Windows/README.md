# Veyron for Windows

Download the one-file installer from the **[Veyron download button](https://github.com/akaiboldiyev/Veyron/releases/latest/download/Veyron-v1-Installer.zip)**.

Do not choose **Code → Download ZIP**; that is the source repository. To install, extract the downloaded installer ZIP and open `Install-Veyron.vbs`.

For complete instructions, see the [main README](../README.md) or the [Russian instructions](../README.ru.md).
