# Veyron v1 для Windows

Windows-версия панели Cyclop. Обычному пользователю не нужно запускать команды: установите Veyron один раз, затем открывайте его из меню «Пуск» или через значок в области уведомлений.

## Установить и запустить

Нажмите **[Скачать Veyron v1 для Windows (.zip)](https://github.com/akaiboldiyev/Veyron/releases/latest/download/Veyron-v1-Installer.zip)**. На странице релиза архив находится в разделе **Assets** под именем `Veyron-v1-Installer.zip`; не скачивайте `Install-Veyron.vbs` отдельно и не выбирайте **Source code**.

1. Откройте папку **Загрузки** в Проводнике Windows.
2. Нажмите правой кнопкой по `Veyron-v1-Installer.zip` → **Извлечь все…** → **Извлечь**.
3. Откройте созданную папку `Veyron-v1-Installer` и дважды щёлкните `Install-Veyron.vbs`. Файлы `.msix` и `.cer` должны быть рядом.
4. После подтверждения установки откройте Veyron из меню «Пуск».

Если установщик сообщает, что не найден `Veyron-v1.msix`, архив не был извлечён целиком. Повторите шаг 2 и запустите скрипт из созданной папки.

Veyron запускается при входе в Windows. Чтобы выключить автозапуск, снимите флажок **«Запускать при входе в Windows»** в меню значка Veyron или в **Настройках** приложения. Отключить автозапуск можно и в параметрах Windows. Команда **«Выход из Veyron»** закрывает приложение до следующего запуска.

Удаление: `Uninstall-Veyron.vbs` или **Параметры Windows → Приложения → Установленные приложения**. Пользовательские настройки, полка и история остаются в `%LOCALAPPDATA%\Cyclop`.

## Сборка

Для разработки нужны Windows 10 версии 1809 или новее, .NET 8 SDK и PowerShell:

```powershell
.\Windows\Build-Windows.ps1
```

Скрипт собирает self-contained x64 MSIX, проверяет его распаковку и создаёт `build/Windows/Veyron-v1-Installer.zip`. Для локальных сборок используется сертификат разработки. Для публичного распространения нужен доверенный сертификат подписи издателя.

Исходная macOS-реализация остаётся в `Sources/Cyclop`. Пользовательские данные хранятся по старому пути `%LOCALAPPDATA%\Cyclop`, поэтому переименование продукта не стирает существующие настройки.
