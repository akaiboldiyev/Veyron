# Veyron для Windows

Скачать установщик можно одной кнопкой: **[Скачать Veyron](https://github.com/akaiboldiyev/Veyron/releases/latest/download/Veyron-v1-Installer.zip)**.

Не нажимайте **Code → Download ZIP** — это архив исходников. Для установки распакуйте ZIP установщика и откройте `Install-Veyron.vbs`.

Полная инструкция: [основной README](../README.md) или [инструкция на русском](../README.ru.md).
